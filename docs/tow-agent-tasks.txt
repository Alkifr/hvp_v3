Этот файл — продолжение работы по буксировкам. В том же коммите есть и другие
незавершённые ранее правки (персонал, дедлайн, цеха, справка). Их не откатывать.


1. Что уже сделано

РМ «Буксировки» — два окна:
- «План» — назначение и правка буксировок.
- «Реестр» — сохранённые строки и письмо по шаблону колонок Excel.
  В письмо попадают только сохранённые строки периода. Черновик формы в письмо не идёт.
  Нужны SMTP и право записи.

На «Плане» три режима. По умолчанию открывается «Неделя».
- «Неделя» — матрица: сверху дни с понедельника по воскресенье, слева время МСК.
  Только начало или конец ручного этапа (placement), если эта отметка попадает в неделю.
  Пребывание, которое лишь пересекает неделю, не показывается.
  Зелёная плашка — буксировка назначена и тянется на её длительность.
  Красная — не назначена, одна клетка шага на самом краю.
  Шаг шкалы: 60 / 30 / 15 / 5 минут. Смены шага держит ту же минуту на экране.
  Интервал длиннее 2 часов обрезается до конца суток и помечается золотой полосой слева.
  Снизу реестр краёв: борт, ангар, начало и окончание буксировки как дата и время.
  Клик по красной — форма «Назначить». Клик по зелёной — «Сохранить» и «Удалить».
- «Шкала события» — одна строка на событие Ганта, чипы на краях.
  Пустой край создаёт одну роль по нормативу. Заполненный открывает правку.
  Кнопка заполняет все пустые края и не затирает занятые.
- «Сутки ангара» — одни сутки МСК, строки по ангарам, только окна движения,
  пересечения подсвечены.

Полный Гант стоянок не копировать.


2. Правила, которые нельзя ломать

- Буксировка лежит внутри события. API отклоняет выход за границы.
- Буксировка привязана к placement.
- Закатка: перрон «МС» → стоянка. Выкатка: стоянка → «МС».
- Пара на разрыве (AUTO_GAP) крепится к соседним ручным этапам.
  На недельной матрице AUTO_GAP не показывать.
- Повторное заполнение краёв не перезаписывает уже занятый край.
- Окончание занятости (occupancyEndAt) отдельно от окончания движения.
- Сдвиг начала уже существующей буксировки требует причину. Без причины API отклоняет.
- Событие DONE только для просмотра.
- Отменённые и DELETED скрыты, как бары Ганта.
- Рабочий контур: MaintenanceEvent.sandboxId = null. Песочница идёт заголовком X-Sandbox-Id.
- Права: tows:read, tows:write. events:write и gantt:write тоже дают запись событий.
  assertCanWriteTow запрещает запись в песочнице только для чтения.
- Норматив длительности края: код EDGE_TOW_MINUTES, по умолчанию 30 минут.
- Время в интерфейсе — МСК, UTC+3, без перехода на летнее время.
- Цвета кнопок сервиса не подменять палитрой HTML-черновика.
  Кнопка по умолчанию белая. Главная кнопка #2563eb.
  Вкладки sandboxesTab, активная нижняя граница #2563eb.
  Поля tgField, карточка белая, приглушённый текст #64748b, основной #0f172a.
  Зелёный назначенной плашки #15803d, красный пустой #dc2626, золотая полоса #ca8a04,
  обводка выбранной #2563eb.
  Чипы «Шкалы» и «Суток» остаются тёмно-синими #1e3a8a. Их не перекрашивать.

API:
- apps/api/src/lib/towBoard.ts и towBoard.test.ts — строки доски.
- apps/api/src/lib/towRegistryMail.ts — письмо по TOW_EXPORT_COLUMNS.
- apps/api/src/lib/edgeTows.ts — planEdgeTows и selectPlannedEdges(plan, role?).
- apps/api/src/routes/planning/tows.ts
    GET /api/tows
    GET /api/tows/board
    POST /api/tows/send
    PATCH /api/tows/:id
- apps/api/src/routes/planning/events.ts
    POST /api/events/:id/tows — своё начало и конец, placementId, откуда, куда.
    POST /api/events/:id/tows/edges — один role или все пустые края по норме.
    PATCH и DELETE /api/events/:id/tows/:towId
- Форма недели создаёт через POST /api/events/:id/tows и правит через PATCH /api/tows/:id.
  Удаление: DELETE /api/events/:id/tows/:towId?changeReason=

Геометрия недели:
- Берутся только MANUAL placement. Край начала — если start внутри [неделя, неделя+7 суток).
  Край конца — если end внутри того же интервала.
- Буксировка покрывает край, если placement совпадает или пуст и граница ближе 2 минут
  либо интервал содержит мгновение края. Берётся ближайшая граница.
- weekEdgeSpan: без буксировки — одна клетка шага. С буксировкой в тех же сутках —
  от минуты начала до минуты конца. Уход за полночь обрезается до 1440.
  Если видимый остаток меньше минуты — снова одна клетка.
- Длинная: длительность больше 120 минут.

Если API отвечает 503, база не открылась: проверять, что *.mdb.yandexcloud.net
не уходит в локальный fake-ip прокси, и что текущий IP клиента разрешён в группе
безопасности кластера.


6. Чего не делать

- Не копировать Гант стоянок в план буксировок.
- Не делать отдельную форму дат основным способом работы. Форма открывается из плашки.
- Не затирать занятый край повторным автозаполнением.
- Не класть несохранённые правки в письмо реестра.
- Не коммитить tmp/tow-week-matrix.html. Это черновик визуализации, не часть сервиса.
- Холст с разбором режимов уже есть и заново его не создавать:
  canvases/tow-plan-workplace.canvas.tsx в каталоге проекта Cursor, не в git.
